Hard rules

  1. Tokens only. Every color, space, radius, shadow, duration, easing, and type size comes from a theme.css custom property.
  2. Functional without JS. Reading, navigation, search fallback, and print all work with scripts off.
  3. Styleguide-first components. New UI pieces land on this page before any page uses them.
  4. No external requests, ever. Fonts, icons, code, and data ride inside the kit folder.
  5. Print styles required. Survival pages get printed and taped to walls; assume paper.
  6. Plain voice. Calm authority, short sentences, zero hype.

Motion

Hover me — the lift runs on --dur-base + --ease-out with --shadow-2.

The whole motion budget is three durations (--dur-fast, --dur-base, --dur-slow) and two easings (--ease-out, --ease-spring). Nothing else moves. Under prefers-reduced-motion every animation freezes site-wide while the kit stays fully usable.
