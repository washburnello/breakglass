Where your API key lives

Portable kits have no server to hold secrets: the key is stored in this browser's localStorage on this device only. It is never written into kit files and never synced anywhere.

  • Prefer a LAN or local endpoint, e.g. http://townbox:11434/v1.
  • The local model service must allow browser calls (cross-origin); for Ollama set OLLAMA_ORIGINS accordingly.
  • Browsers block plain http:// endpoints from https:// pages — test LAN boxes from the portable file:// copy.
  • Anyone at this machine can read the key out of the browser — use Forget (below) on shared computers.
  • Served kits should eventually use a server-side proxy instead of browser-held keys (planned in plan.md).
