Pocket Apps

Files first, always

Every app autosaves to this browser as you work, but files are the real home for your data: use each app's Save button to download your document and Open to bring it back — on this computer or any other. Browsers clear saved state without warning; downloaded files don't.

NotepadPlain-text notes that save anywhere. PaintQuick sketches, diagrams, signs. SpreadsheetGrids, sums, and supplies math. To-DoTasks with priorities and due dates. CalendarMonth view with day events.

Working offline

  • All five run from the plain folder — no server needed, ever.
  • Documents open across apps' file formats are ordinary (.txt, .csv, .json, .png), so nothing here traps your data.
  • Each app prints cleanly; paper copies survive dead batteries.
