How to Use This Site

The short version

BreakGlass is a self-contained knowledge kit. It works from a USB stick with no internet, no installation, and no power-hungry hardware — and it works even better when served on a home network. Start at the home page's tiles, search when you know what you need, and print anything you might need when screens are dead.

Two ways to run it

ModeHowWhat changes
PortableCopy the folder anywhere (USB drive included) and double-click index.htmlEverything core works; features that truly need a server show an honest badge instead of breaking
ServedOpen breakglass.w4sh.net, or run the bundled START-SERVER wrapper and visit the address it printsAdds big add-on packs: full-size wiki/repair libraries, emulator systems needing more memory, and network tools

Finding things

  • Tiles first. The home page groups the kit into Survival, Knowledge, Rebuild, Tools, and Morale sections.
  • Search everything with the box in the top bar of every page; results rank titles strongly.
  • A–Z index lists every page when you'd rather browse than guess words (a-z.html).
  • Big libraries are separate: wiki and repair-guide archives open from their own pages and search within themselves — by design, so the whole kit stays small.

Situation phases

The selector in the top bar (Everyday · Survive · Stabilize · Rebuild · Thrive) re-tunes the kit for what's happening: Survive lifts water-and-first-aid material, Stabilize surfaces sanitation and comms, and so on. Nothing is ever hidden — phases only reorder priorities. The Emergency page always shows survival guidance no matter the setting.

Printing is a feature

Checklists, dose tables, and guides are built to print cleanly: headers and buttons drop away, ink-safe colors take over. If a storm is coming, printing the water, bleeding, and burn pages costs one sheet each and works with the power out.

Your stuff stays yours

  • Apps save as ordinary files (.txt, .csv, .json, .png) via their Save/Open buttons — files are the real storage; browser autosave is just a convenience.
  • The Schoolhouse tracker exports each student as a portable file.
  • No accounts, no tracking, no internet calls — ever.

Safety framing

Medical and safety pages are educational references grounded in public-domain government guidance. They support — never replace — professional care, local authorities, and product labels. When help is reachable, use it.

Start here

New to the kit? Open START-HERE, skim the home page tiles, and try the phase selector. That's the whole learning curve.
